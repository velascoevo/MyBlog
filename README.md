# Vértice — Blog

Blog informativo en español, creado como una página web estática con HTML, CSS y JavaScript.

## Contenido

- Portada con presentación del blog y enlaces de navegación.
- Sección de artículos con tarjetas de tecnología, diseño y cultura.
- Formulario de suscripción con validación del correo y confirmación visual.
- Diseño adaptable a móviles y escritorio, con tema oscuro en tonos azules y cian.

## Cómo abrirlo

Abre `index.html` directamente en un navegador. No requiere instalación ni dependencias.

> El formulario de suscripción es demostrativo: muestra una confirmación en pantalla, pero no envía ni guarda los correos.

## Estructura

- `index.html`: página, estilos y comportamiento del blog.
